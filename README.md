## plus

標準入力から整数を読み込み、その合計を計算して標準出力に表示するコマンドです。

### 使用方法

以下のコマンドで実行できます。

```bash
seq 5 | ./plus
```

### 実行結果

```text
15
```

### 入力について

- 標準入力から整数を1行ずつ読み込みます。
- 入力された整数の合計を表示します。
- 不正な入力や入力がない場合はエラー終了します。

### 必要な環境

- Python 3
